納入與排除篩選邏輯 (Filtering Rules)：
【納入 (✅)】：
1. 正式獨立販售的 Expansion、Mini-Expansion。
2. 正式獨立販售的 Scenario / Campaign / Map Pack。
3. 正式獨立販售，且增加一個可在正常遊戲中運作之獨立 gameplay module。
4. Kickstarter Exclusive / Stretch Goals：若後續有另外獨立上架零售，則 ✅ 納入計算。

【排除 (❌)】：
1. Promo / 首刷贈品 / 隨其他產品附送 / 1–2 張 Promo 卡。
2. 免費 Web 下載 / Codex / Fan-made 模組。
3. 主要為配件升級、替換元件、少量附加卡（如金屬幣、木指示物、純修訂卡）。
4. Big Box / Bundle / Compilation：不作為獨立 Expansion 排名，將其 Own 數量拆解併入其包含的 Base / Expansion 計算。
特殊遊戲綁定與歸屬規則 (Game-Specific Mapping Rules)：
1. Edition 定義：主要以bgg頁面。官方對原 Base Game 進行實質性規則或遊戲內容修訂後發行的新版本（如 2nd Edition, Revised Core）。單純換出版社、換美術、多國語言版、配件升級、單純重印，即使產品名稱不同，也不視為新的 Edition。
2. Arkham Horror: The Card Game：2016 年原版與 2021 年 Revised Core Set 視作【同一個 Base】合併計算。
3. Star Realms：Star Realms: Colony Wars 與 Star Realms: Frontiers 納入 Star Realms。
5. Dune: Imperium：Rise of Ix、Immortality、Bloodlines 僅納入最接近的 Base Game（如 Dune: Imperium 或 Dune: Imperium – Uprising）。
6. Concordia：任何 Concordia 擴充【不納入】Concordia Venus。
7. Nemesis：任何 Nemesis 擴充【不納入】Nemesis: Lockdown。
8. Wingspan：Wingspan: Oceania Expansion 【不納入】Wingspan Asia。
使用率計算(Usage)：
• Expansion Own = 直接持有 Expansion 的人 + 持有 Big Boxes 包括 Expansion 的人
• Base Own = 直接持有 Base 的人 + 持有 Set 包括 Base 的人
• Direct Owned = 直接持有 Expansion 的人
• Big Boxes = 有多少個 Big Boxes 包括這個擴充
• Usage = Expansion Own ÷ Base Own × 100%
• Direct Usage = Direct Owned ÷ 直接持有 Base 的人 × 100%

同一擴充納入多個 Base Games 會分別計算各 Base Game 使用率；「全部擴充排名」採用其中最高使用率作為排名值，並保留所有 Base Game 名稱。
注意：BGG 的持有數是作品層級統計，不是同一批玩家的去重名單。

• ≥ 30.0% : 5 星 ★★★★★ 閉眼買（社群公認必備神擴）
• 20.0% ~ 29.9% : 4 星 ★★★★☆ 強烈推薦（開 5 次以上直接買）
